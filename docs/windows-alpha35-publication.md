# Публикация Windows alpha.35

По команде пользователя 11 ноября 2026 года опубликован предварительный выпуск
[v0.2.0-alpha.35](https://github.com/sanekman/1C-Backup/releases/tag/v0.2.0-alpha.35).
Время публикации: **12:36:58 UTC**. Это alpha, **без Authenticode-подписи**;
этап 7 и условия beta полностью не закрываются.

## Исходник и пакет

- Тег: **v0.2.0-alpha.35**, исходник **0da787dac345567ef64e2079df1ba9b870635b9a**.
- SDK **10.0.402**; включённые .NET, Windows Desktop и ASP.NET Core — **10.0.13**.
- От принятого кандидата **6f7c65a** отличаются документы и сгенерированная
  справка; продуктовый код не менялся. Для настоящего номера alpha.35 пакет
  пересобран и проверен заново: версия `0.1.0-dev` не переименовывалась в релиз.
- Ветка автообновления: `distribution/windows-x64-0.2.0-alpha.35`, коммит
  **d150cbae7577fe92745f03d9d8682d4cf6704542**.

## Проверка опубликованного обновления

[Прогон 43021913566](https://github.com/sanekman/1C-Backup/actions/runs/43021913566)
успешен. Штатный клиент из исходника **0da787d** получил текущую версию
`0.2.0-alpha.34` как параметр и выбрал **alpha.35**, скачал **65726291** байт
из новой ветки дистрибутива и подтвердил SHA-256 установщика выше.
Прогресс достиг 100%, проверенный кеш использован повторно без перезаписи,
для alpha.35 обновление снова не предлагается; частичных файлов и повторов нет.
[Отчёт 13854788780](https://github.com/sanekman/1C-Backup/actions/runs/43021913566/artifacts/13854788780).
Это проверка скачивания, а не запуск установленного старого Windows-приложения.
Linux-хост этой проверки использовал runtime **10.0.15**; он не входит в
опубликованный Windows-пакет, в котором подтверждён **10.0.13**.

Дополнительно тот же production-клиент из **0da787d** выполнен в рабочем Linux-
окружении с SDK **10.0.402** и единственным установленным runtime **10.0.13**,
без токена GitHub. Результат успешен: та же alpha.35, размер и SHA-256,
100%, повторное использование кеша, отсутствие повторного предложения и
частичных файлов. SHA-256 `result.json`:
`dcc56bb85afeb2dd9d2731534727eb55a8a0eaf8b1a6c352d19d356d981cb216`.

## Сохранённые ограничения

Windows 11, Server 2016/2019, домен, внешний NAS, UAC, настоящая перезагрузка
и независимое прохождение новичком остаются непроверенными в соответствующих
границах этапа 7. Сертификата подписи нет. Пропущенные DT/восстановление/отмена
настоящей 1С и открытый UNC-сеанс не объявляются успешными; удалённый MS SQL
под службой ожидает стенда. Telegram/MAX — отдельная задача.

Ранее опубликованные alpha.34 и Server preview.8, их теги и дистрибутивы
не заменены. Проверено сохранение прежних refs: alpha.34 и server-preview.8
указывают на **9f4b7337f41088a4e0b312a7c0f073d439b4cc43**, ветка Windows alpha.34 —
на **3d34770982eac6a5852fd87b08ea11331d49619d**. Новый серверный выпуск не создавался.
PR №2 остаётся открытым черновиком; слияние не выполнялось.
