История показывает «Частично» и результат по каждому хранилищу; отмена сохраняет уже доставленные копии. Старые задания совместимы.

После ручного запуска выбранное задание показывает понятный итог и индикатор выполнения без приблизительного процента. Кнопки «Последняя копия» и «Результат» сразу открывают нужный файл в каталоге или последний запуск в истории. Переход к результату снимает скрывающие запись фильтры; подробности запуска показывают местное время и сохраняют технические UTC-метки.

Переработан интерфейс: список заданий занимает всю ширину, настройка проходит через четыре шага с проверками полей и итогом. Кнопки мастера остаются видны при прокрутке; редкие параметры свёрнуты. Главное действие для расписания — «Включить автоматически». Выбранное задание показывает последний результат и время следующего события; таблицы используют местное время компьютера. Окно по умолчанию 1100×740, поддерживается компактный размер 900×580.

Добавлено шифрование ZIP паролем (AES-256) для файловой 1С, выгрузок .dt и SQL-копий при доставке на локальный диск, UNC или FTP / FTPS. В редакторе задания задайте пароль и сохраните настройки. Пароли находятся в хранилище Windows текущего пользователя; смена пароля действует на новые копии. Старые копии сохраняют прежний пароль. Извлечение 1Cv8.1CD поддерживает сохранённый или введённый вручную пароль. ZIP открывается в 7-Zip / WinRAR, имена файлов остаются видимыми. Исходные базы, временные выгрузки и копии на стороне SQL-сервера этим не шифруются.

Добавлены отдельный фоновый агент текущего пользователя, запуск и остановка из интерфейса, автозапуск при входе в Windows, общий замок исполнения и автоматический опрос внешних SQL-копий с отдельными интервалами. В интерфейсе доступны список заданий, выбор путей, поиск, история, каталог копий и ручная проверка SHA256.

Расписание поддерживает до 48 времён запуска в день, например `09:00, 13:00, 23:00`, с выбранными днями недели и часовым поясом. Старые задания сохраняют своё время. В истории доступны фильтры результатов, поиск, подробности ошибок и экспорт видимых записей в JSON. Выбранная резервная копия показывает полный путь и контрольную сумму. В SQL-мониторинге доступны выбор каталога, отмена ручной проверки, подробности наблюдений и удаление источника с сохранением истории. Ошибки утилит PostgreSQL записываются в локальные диагностические журналы. Исправлен ранний запуск во время сохранения задания.

Фоновый агент поддерживает автономный режим; окно можно закрыть после запуска агента. Остановка отменяет текущую операцию и дожидается сохранения истории. Работа без входа пользователя в Windows потребует службы, которая ещё не реализована. Сетевой обмен с сервером управления пока не включён.

В составе нет платформы 1С, СУБД или утилит PostgreSQL. ZIP файла 1Cv8.1CD требует закрытых сеансов базы, выгрузка .dt — установленной платформы 1С. SQL Server использует Windows-аутентификацию и проверку сертификата TLS.

Копии проверяются по размеру и SHA256; проверка не заменяет пробное восстановление базы. Дистрибутив не подписан. Перед обновлением остановите агент и планировщик, замените всю папку программы и запустите агент снова.

Для локальных и сетевых архивов файла базы добавлено извлечение `1Cv8.1CD` в новую папку: проверяются размер, SHA256 и единственный файл архива. Существующие базы и исходные копии сохраняются. FTP и восстановление SQL-баз этим действием пока не поддерживаются.
