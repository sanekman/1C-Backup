# 1C-Backup 0.2.0-alpha.2 — Windows x64

Исправлено аварийное закрытие окна при начале отправки копии в хранилища. Шкалы доставки теперь читают проценты, не пытаясь записать их в свойства состояния задания. Ошибка подтверждена диагностикой alpha.1: архив уже создавался, но окно завершалось при отображении прогресса доставки.

Усилена Windows-проверка интерфейса: проверяются созданные шкалы двух хранилищ с разными процентами и режим их привязки. Добавлена проверка XAML, доступная на Linux.

Установщик и ZIP содержат номер версии в имени. Сохранена совместимость автообновления с прежними preview и alpha.1. Перед ручной установкой завершите приложение и агент; работающую службу остановите. Настройки и история сохраняются.

Дистрибутив пока не подписан. Пакет, целостность установщика и скачивание через автообновление проверяются в Linux; нативную установку и отображение шкал требуется проверить на Windows. Прерванный запуск из alpha.1 не следует считать успешной доставкой копии.
