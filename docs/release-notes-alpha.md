# 1C-Backup 0.2.0-alpha.13 — Windows x64

Добавлено хранилище «Шлюз хранилища (Proxmox)» для основного и дополнительных назначений. Контейнер или служба в Debian 12 LXC принимает копии и сохраняет их в подключённую папку/диск/NAS. Шлюз устанавливает исходящее WSS-соединение; входящие порты на нём не открываются.

Внутри ретрансляции используется отдельный канал взаимного TLS агента и шлюза. Доступ разрешён только сопряжённым сертификатам; публичный ретранслятор не получает закрытые ключи. Для этого назначения обязателен пароль архива. После получения шлюз проверяет размер и SHA-256 и атомарно публикует файл. Поддерживаются скачивание, проверка, удаление и собственный лимит копий, включая защиту инкрементных цепочек. При сбое доставки другие назначения продолжают работать.

Основная программа, её фоновый агент или служба могут обслуживать публичный узел: включите его импортом hub.json в настройках. По умолчанию узел выключен и слушает только loopback. Публичный HTTPS обслуживает Caddy, IIS или Apache. Включены конфигурации Let’s Encrypt, пример IIS reverse proxy и скрипт win-acme; Apache использует mod_md. Подробная локальная инструкция доступна из настроек и в Help/storage-bridge.txt.

Публичный узел требует доступного из интернета домена и входящего HTTPS. Let’s Encrypt обычно требует 80/443 либо настроенный DNS-01. Если обе стороны находятся за NAT без входящего доступа, используйте отдельный публичный узел. Контейнер не делает сеть публичной самостоятельно.

Файл client-pairing.json содержит секреты — передавайте и храните его защищённо. В Windows токен и пароль сертификата сохраняются в защищённом хранилище, PFX остаётся зашифрованным; поддержан доступ службы. Пароль архива хранится отдельно и не передаётся шлюзу. JSON заданий не содержит закрытых ключей и токенов. Внутренние сертификаты действуют 3 года и требуют повторного сопряжения при перевыпуске; публичные Let’s Encrypt продлеваются прокси автоматически.

Проверены настоящий контейнер шлюза, HTTPS Caddy с доверенным тестовым сертификатом, взаимный TLS, загрузка/скачивание/удаление, квота, отказ чужого сертификата и токена, прерванная загрузка и перезапуск. Установщик LXC проверен в Debian 12 с записью вызовов systemctl; настоящий Proxmox/systemd, IIS и WPF здесь не запускались. Выпуск Let’s Encrypt на реальном домене не выполнялся. При разрыве загрузка повторяется с начала; возобновление по блокам пока не реализовано.

Перед обновлением завершите приложение и агент или остановите службу. Настройки и копии сохраняются. Установщик пока не подписан.
