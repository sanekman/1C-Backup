# 1C-Backup 0.2.0-alpha.5 — Windows x64

При резервном копировании файлов и папок отказ доступа или занятый файл больше не отменяют всё задание. Программа формирует архив доступных данных и завершает задание с предупреждениями: в результате перечислены пропущенные пути. Полный список находится в onec-backup-manifest.json внутри архива.

Неполная копия отмечается в каталоге и при восстановлении. Она создаётся как самостоятельная полная копия, даже при инкрементном задании, и не используется как основа следующей инкрементной копии. При её создании очистка хранилищ пропускается: прежние копии сохраняются. Неполные архивы не учитываются в лимите обычных копий и автоматически не удаляются; при необходимости удалите их вручную.

Ошибки диска, отмена задания и изменение копируемого файла остаются ошибками. Для баз 1С правила доступа не изменены. Подробнее: docs/partial-file-backups.md. Для проверки и восстановления неполных копий через программу нужна alpha.5 или новее.

Проверены сценарии отказа доступа, занятого файла, восстановления доступных данных и сохранения прежних инкрементных цепочек. Целостность Windows-пакета и скачивание проверяются в Linux; нативный GUI и установка на Windows здесь не запускаются. Установщик пока не подписан.

Включены Google Drive, исправления шкал прогресса и установка на Windows Server 2016+. Перед ручной установкой завершите приложение и агент; службу остановите. Настройки и история сохраняются.
