# 1C-Backup 0.2.0-alpha.4 — Windows x64

Добавлено хранилище Google Drive: основное или дополнительное назначение, отдельный лимит копий, вход через браузер, загрузка больших файлов частями, обратное чтение с проверкой SHA-256, сохранение копии на компьютер и общая очистка истории. Подключение работает через API; синхронизируемая папка Google Drive не нужна.

Для первого подключения нужен OAuth JSON клиента типа Desktop app из Google Cloud с включённым Google Drive API. Общего OAuth-клиента проекта пока нет. Настройка: docs/google-drive.md. Пароль Google вводится только на сайте Google; refresh token защищённо сохраняется в Windows и экспортируется в кэш службы. Доступ ограничен файлами приложения (drive.file).

Архивирование / AES-256, временная папка, одновременная отправка в другие хранилища и независимое количество копий сохраняются. Проверка Google Drive читает копию из облака и расходует входящий трафик. После обрыва следующая попытка создаёт новую копию.

HTTP-адаптер и OAuth-поток проверены автоматически с моделированными ответами. Реальный вход в Google и работа Windows-службы с этим подключением ещё требуют проверки с вашим OAuth-клиентом. Целостность Windows-пакета и скачивание проверяются в Linux; нативный GUI здесь не запускается. Установщик пока не подписан.

Включены исправления шкал прогресса и установка на Windows Server 2016+ из предыдущих alpha. Перед ручной установкой завершите приложение и агент; службу остановите. Настройки и история сохраняются.
