# 1C-Backup 0.2.0-alpha.11 — Windows x64

Фоновый агент продолжает работать при временных ошибках доступа и ввода-вывода: чтении расписания и команд, записи состояния и прогресса. В окне автоматического копирования появляется предупреждение. После восстановления доступа агент повторяет служебную операцию и снимает её предупреждение. Одинаковая непрерывная ошибка не заполняет диагностический журнал повторными записями каждую секунду.

При недоступных настройках или истории запусков агент остаётся включённым, но ждёт восстановления доступа перед выполнением заданий. Настройки не сбрасываются. Ошибка записи отметки запуска при загрузке системы не мешает другим заданиям; такое задание будет проверено повторно. Полная остановка работает даже при невозможности записать состояние агента.

Отказ в доступе во время копирования остаётся ошибкой конкретного задания, если пригодная копия не была создана. Агент показывает предупреждение и продолжает расписание. Если архив файлов и папок можно сформировать с пропусками, сохраняется прежнее поведение: неполная копия и список пропусков. Исправление не предоставляет дополнительных прав на файлы и не превращает неудачную копию в успешную.

Ошибки повреждённой конфигурации и невозможность получить исключительное владение рабочим профилем остаются причинами отказа запуска: выполнять задания с неизвестными настройками или параллельно другому агенту нельзя. Если весь рабочий профиль недоступен, предупреждение может быть записано только в диагностику, пока запись состояния не восстановится.

Включены исправления автообновления alpha.10, компактное окно, анимация трея и остановка текущего задания. Целевая платформа: Windows Server 2016–2025 x64 с графическим интерфейсом, Windows 10 22H2 и Windows 11.

Проверены продолжение после отказа в доступе, ожидание восстановления настроек, восстановление записи состояния, полная остановка, повтор чтения расписания и отметки загрузки системы. Автоматические тесты и проверка целостности Windows-пакета выполняются в Linux; нативную установку и GUI Windows в этой среде не запускали. Установщик пока не подписан.

Перед ручной установкой завершите приложение и агент или остановите службу. Настройки и история сохраняются.
