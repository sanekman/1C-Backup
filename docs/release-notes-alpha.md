# 1C-Backup 0.2.0-alpha.1 — Windows x64

Первый выпуск с обозначением «альфа». Номер версии теперь входит в имена установщика и ZIP: `1C-Backup-0.2.0-alpha.1-windows-x64-setup.exe` и `1C-Backup-0.2.0-alpha.1-windows-x64.zip`.

Версия 0.2.0 позволяет перейти с 0.1.0-preview.45 через автообновление. Для прежних клиентов сохранён технический установщик с прежним именем: его содержимое и SHA-256 совпадают с версионным EXE. Ссылки для скачивания ведут на версионные файлы.

Включены возможности предыдущих выпусков: резервное копирование 1С, SQL, файлов / папок и WebDAV, расписание, несколько хранилищ с отдельными лимитами, архивация и шифрование, диагностика, трей, автообновление и служба Windows с выбором пользователя. Установка по умолчанию в Program Files.

Перед ручной установкой завершите приложение и фоновый агент; работающую службу остановите. Настройки и история сохраняются. Для выбора другой учётной записи службы удалите службу и установите её заново.

Это альфа-версия для тестирования. Дистрибутив пока не подписан цифровой подписью. Создание Windows-пакета, целостность файлов и автообновление проверяются; установка, UAC и работа службы под выбранным пользователем требуют проверки на Windows. Полная проверка восстановления на реальных базах остаётся необходимой перед использованием для рабочих данных.
