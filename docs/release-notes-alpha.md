# 1C-Backup 0.2.0-alpha.12 — Windows x64

Добавлены оповещения о результатах резервного копирования в Telegram и MAX. Настройка: «Настройки → Оповещения: Telegram и MAX → Настроить оповещения». Можно выбрать ошибки, предупреждения, успешные копии и отмену. По умолчанию включены ошибки и предупреждения. Каждый канал имеет отдельный токен бота и ID получателя; доступны тестовое сообщение и подробная инструкция «Как подключить».

Сообщения отправляются отдельно от копирования. При ошибке доставки появляется предупреждение и выполняется повтор через минуту; второй канал продолжает работать. История результатов служит очередью, успешные доставки отмечаются на диске. При обычном перезапуске повторной рассылки нет. При обрыве после приёма сообщения сервисом или ошибке записи отметки возможно дублирование.

Токены сохраняются в защищённом хранилище Windows, предусмотрен режим службы через существующий защищённый механизм передачи секретов. JSON-настройки содержат только ссылки на токены. В сообщение включаются компьютер, имя задания, результат и локальное время; пути, пароли и полный текст ошибок не отправляются. Диагностика содержит события доставки без токенов и текста сообщений.

Настройки применяются без перезапуска. Включение канала, смена получателя или набора событий начинают отправку с новых результатов. Для доставки должно работать приложение, приложение в трее или фоновый агент/служба. Оповещения внешнего мониторинга SQL и отдельные системные события агента пока не включены.

Используются официальные HTTPS API Telegram и MAX (`platform-api2.max.ru`), перенаправления запрещены, проверка TLS не отключается. Для MAX нужен бот, доступный владельцу согласно правилам платформы. Для Telegram получатель должен начать переписку с ботом либо добавить его в группу/канал.

Проверены запросы и ответы API на моделях, выбор событий, сохранение отметок доставки, повтор после ошибки, независимость каналов, отмена и защита от неправильных токенов и больших ответов. Реальные сообщения и нативные WPF/Windows-служба в этой среде не проверялись: используйте кнопку тестовой отправки со своим ботом. Включено исправление устойчивости агента alpha.11. Установщик пока не подписан.

Перед ручной установкой завершите приложение и агент или остановите службу. Настройки, история и копии сохраняются. Подробности подключения: Help/notifications.txt внутри установки и docs/notifications.md в репозитории.
