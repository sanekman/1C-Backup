# 1C-Backup 0.2.0-alpha.3 — Windows x64

Исправлена проверка ОС установщиков для Windows Server: теперь разрешены Server 2016 (сборка 14393), 2019, 2022 и 2025 x64. Прежний общий порог 19045 ошибочно блокировал Server 2016 и 2019. Для рабочих станций сохранено требование Windows 10 22H2 / Windows 11.

Первый целевой сервер — Windows Server 2016 x64 с Desktop Experience и обновлениями ОС. .NET 10 поддерживает эту ОС; среда входит в дистрибутив. Полная нативная проверка GUI, службы, SQL и обновления на Server 2016 ещё требуется. Матрица и сценарии проверки: docs/windows-compatibility.md.

Включено исправление аварийного закрытия шкал прогресса из alpha.2. Перед ручной установкой завершите приложение и агент; работающую службу остановите. Настройки и история сохраняются. Установщик пока не подписан цифровой подписью.
