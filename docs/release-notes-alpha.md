# 1C-Backup 0.2.0-alpha.17 — Windows x64

Сообщение «Копия создана, есть предупреждения» теперь использует предупреждающий цвет, а не цвет ошибки. Успешная доставка доступных файлов, неполная копия и ошибка копирования остаются различимыми в компактном интерфейсе. Windows-проверка создаёт реальную копию с заблокированным файлом и проверяет цвет результата.

Проверка SHA-256 больше не скрывает неполноту копии: после успешной проверки архив с пропусками отмечается «С пропусками», а проверка последних копий показывает количество неполных архивов и раскрывает предупреждение. Совпадение контрольной суммы не возвращает файлы, пропущенные при создании архива.

Рабочая папка восстановления и новая папка с восстановленными файлами создаются с закрытыми правами (текущий пользователь и SYSTEM на Windows, владелец на Linux). Готовая папка сохраняет эти права. Это защищает распакованные данные зашифрованного архива от доступа через общие права родительской папки.

Обновлена зависимость Microsoft System.Security.Cryptography.Pkcs до исправленной 10.0.13 (включая DLL в автономном дистрибутиве) для устранения предупреждений CVE-2026-84008 и CVE-2026-70162. Встроенный .NET обновлён до 10.0.13, SDK и контейнерные сборки — до 10.0.402. Версия SQL-клиента не меняется.

Уточнены подсказки в истории запусков и свойствах неполной копии: предупреждение может означать пропуск отдельных файлов, остальные файлы доступны для восстановления. Список пропусков находится в индексе архива. Исправлено чтение русских сообщений при проверке отдельного серверного пакета на Windows. Проверка интерфейса охватывает предупреждения об очистке и пропущенных файлах.

При копировании файлов и папок изменение размера или содержимого отдельного файла, его удаление и ошибка чтения больше не отменяют всю копию. После ошибки источника программа повторяет создание полной копии из доступных файлов. Неудачные файлы пропускаются; результат содержит предупреждение, количество пропусков и их имена. Полный список находится в onec-backup-manifest.json внутри архива.

Файлы проблемного задания предварительно читаются и проверяются по одному в выбранной временной папке, затем добавляются в ZIP. Ошибка чтения не оставляет повреждённую запись в архиве. Уже сохранённые версии файлов не отбрасываются из-за последующих изменений источника. Дополнительное место во временной папке требуется для одного исходного файла за раз. Временные данные ограничены правами текущего пользователя и SYSTEM на Windows и удаляются после выполнения или отмены.

Частичные копии проверяются, передаются во все выбранные хранилища и поддерживают шифрование и восстановление с предупреждением о пропусках. Они не удаляют предыдущие хорошие копии и не становятся основой следующей инкрементной цепочки. Ошибки записи архива, проверки его целостности и доставки не подменяются успешным результатом.

Проверены изменение размера после сканирования, изменение содержимого без изменения размера, удаление файла, сбой чтения в середине файла и ZIP-записи, несколько хранилищ, зашифрованное восстановление, сохранение предыдущих копий и отмена с очисткой временных данных.

Перед обновлением полностью завершите приложение и агент или остановите службу. Настройки и копии сохраняются. Установщик пока не подписан.
