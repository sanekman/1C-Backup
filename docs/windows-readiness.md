# Состояние готовности Windows

Актуальная последовательность работ, небольшие подблоки, зависимости и критерии завершения находятся в [новой дорожной карте Windows](windows-roadmap.md).

## Текущее состояние

Последние опубликованные версии: **Windows v0.2.0-alpha.34** и **Server v0.1.0-preview.8**.

В `feature/local-backup-agent`, PR №2, накоплен невыпущенный пакет: отчёты предварительных проверок, сохранение TXT, повтор проверки, панель ручных запросов и прогноз расписания.

**Этап 1 завершён: подблоки 1.1–1.6 приняты.** Пройдены общий Windows UI-прогон, профильные и общие тесты, проверка установленной службы и установочного пакета. Снимки компактного интерфейса просмотрены; исходный код приёмки — `bd182b770e0c81ba5ae6e1fffe33b55bd08d28eb`. Подробности и ссылки на прогоны — в [отчёте приёмки](windows-stage1-acceptance.md). **Этап 2 в работе:** связанным пакетом добавлены примеры и проверки ввода источников, пояснения SQL/NAS, проверка источника через работающую службу и инструкция первого запуска. Общая Windows-приёмка этого пакета ещё не завершена. Это завершение пакета в ветке, новый выпуск не опубликован.

Наличие реализации и успешная сборка не означают прохождение проверки на всех Windows. Реальные сеансы 1С, удалённые СУБД, доменные перезагрузки и полная матрица целевых ОС остаются отдельными стендовыми проверками.

Windows остаётся приоритетом. Linux и Telegram/MAX рассматриваются отдельно; существующие выпуски сохраняются. Связанные доработки проверяются пакетами, без повторения полного CI после каждого небольшого изменения.
