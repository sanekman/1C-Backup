# Состояние готовности Windows

Актуальная последовательность работ, небольшие подблоки, зависимости и критерии завершения находятся в [новой дорожной карте Windows](windows-roadmap.md).

## Текущее состояние

Последние опубликованные версии: **Windows v0.2.0-alpha.34** и **Server v0.1.0-preview.8**.

В `feature/local-backup-agent`, PR №2, накоплен невыпущенный пакет: отчёты и действия проверок, ручная очередь, прогноз расписания, примеры источников, пояснения подключений/NAS, проверка источника работающим агентом/службой и инструкция первого запуска.

**Этапы 1 и 2 завершены: подблоки 1.1–1.6 и 2.1–2.5 приняты.** Пройдены общие Windows UI-сценарии, профильные и общие тесты, нативная служба, установщик и обновление. Снимки просмотрены; исходный код приёмки этапа 2 — `0e4ca90a9e3f2b9b65432fd9d6ddbfe386977ca5`.

**Этап 3 завершён: подблоки 3.1–3.6 приняты** на исходнике 939213380dea403ec6615713b083d477eabec8dd. Настоящий Windows-стенд подтвердил три разные загрузки, запуск службы до входа, пользовательский автозапуск, смену пользователей службы, квоту/заполненный том, сохранность и восстановление архивов. Все семь CI-прогонов успешны; Windows — 959 общих и 6 профильных тестов без ошибок/пропусков.

Подробности: [этап 1](windows-stage1-acceptance.md), [этап 2](windows-stage2-acceptance.md), [этап 3](windows-stage3-acceptance.md). Следующая работа — **этап 4: 1С и SQL на Windows**. Частичные проверки 1С на alpha.34 записаны [отдельно](windows-onec-results.md); пользователь отложил продолжение до 10 ноября. [Стенд полного MS SQL](windows-sql-stand.md) подтвердил локальный Windows-вход через Shared Memory, SQL-вход по TCP/TLS, две копии с восстановлением и чтение реальных Full/Diff/Log. Удалённый SQL, Windows/TCP и служба SP Backup остаются отдельными проверками. Пункт 4.5 принят: актуальность внешнего наблюдения, ошибка/восстановление опроса и правильные расшифровки текущего отчёта в панели. Проверены смена источника, история за пределами первой страницы, изоляция агентов и часовой пояс; [приёмка передачи и отображения](windows-observation-acceptance.md). Принята матрица PostgreSQL 15–18: 18 результатов с реальными дампами, восстановлением Unicode, отказом старых утилит и сохранностью прежних копий. Матрица выполнялась под пользователем Windows; проверка SCM с делегированным паролем/TLS принята отдельно. [Подробности](windows-postgresql-compatibility.md). Новый выпуск не опубликован.

Наличие реализации и успешная сборка не означают прохождение проверки на всех Windows. Реальные сеансы 1С, удалённые СУБД, доменные перезагрузки и полная матрица целевых ОС остаются отдельными стендовыми проверками.

Windows остаётся приоритетом. Linux и Telegram/MAX рассматриваются отдельно; существующие выпуски сохраняются. Связанные доработки проверяются пакетами, без повторения полного CI после каждого небольшого изменения.
