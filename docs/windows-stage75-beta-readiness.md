# Пункт 7.5. Готовность SP Backup к beta

По состоянию на 18 ноября 2026 года (Владивосток) технические результаты
по текущим выпускам сведены. **Широкая beta пока не готова.** Основные
Windows-сценарии проверены на Server 2025, а на CT 107 принят переход
до preview.11 через панель. Для решения о beta остаются матрица Windows,
внешние стенды и подпись установщиков.

## Открытые условия

| Пункт | Что требуется |
| --- | --- |
| 7.1. Матрица ОС | Для заявления поддержки Windows 11 или Server 2016/2019 нужны проверки точных пакетов на отдельных стендах. Windows 10 22H2 также остаётся вне подтверждённой матрицы этого отчёта. [Матрица Windows](windows-compatibility.md) |
| 7.2. Эксплуатация Windows | Остаются обычный пользователь с UAC, доменная служба, проверка NAS под службой и восстановление с NAS, повторный вход и реальная перезагрузка на целевых стендах. [Приёмка этапа 7](windows-stage7-acceptance.md) |
| 7.4. Подпись | Сертификат издателя недоступен. Установщики агента и Windows-сервера неподписаны. Данное условие beta остаётся в силе до отдельного решения. [Дорожная карта](windows-roadmap.md#74-подпись-установщиков) |
| 4.3.2. Удалённый MS SQL | Нужны отдельные Windows-машины для SQL и агента со службой, проверка входа по TCP, доставки и восстановления тестовой БД. [SQL-стенд](windows-sql-stand.md) |
| 4.1.2 и 4.2.1–4.2.2. 1С | Пользователь решил пропустить открытый UNC-сеанс и приёмку DT, восстановления и отмены новым агентом. Подтверждения для этих сценариев отсутствуют. [Нативные результаты 1С](windows-onec-results.md) |

## Решение о выпуске

По действующим условиям широкую beta стоит отложить до появления стендов и
сертификата. Если нужен ограниченный выпуск раньше, для отдельного решения
можно взять файловые сценарии и Server 2025 x64 как базу подтверждённой
матрицы. Результаты Server 2022 подходят для оценки совместимости. Для
включения точных новых пакетов на этой ОС потребуется отдельная проверка.
LXC можно описать в границах штатного Debian 13 x64 с исправленным
системным обновлятором. Доставку на внешний NAS можно указывать как подтверждённую для окружения
пользователя. Доменная работа с NAS, восстановление с NAS, удалённый MS SQL
и пропущенные сценарии 1С остаются за пределами подтверждённой приёмки. Для выпуска без
подписи потребуется явное решение об изменении 7.4.

После согласования объёма стоит зафиксировать версию и состав beta, а затем
связать заметки выпуска с [установкой агента](user-guide.md),
[первым запуском Windows-сервера](server-first-start.md),
[подготовкой возврата Windows-сервера](server-upgrade-backup.md) и
[обслуживанием LXC](server-proxmox.md). Перепроверять нужно изменившиеся пакеты,
способы установки и новые условия. Пункт 7.5 в части итогового отчёта выполнен.
Решение о beta остаётся открытым.
