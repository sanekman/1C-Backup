# Результаты проверки настоящей платформы 1С

## 9 ноября 2026 года: частичная приёмка файловой базы

Пользователь выполнил изолированный сценарий на своём Windows-компьютере с платформой **8.5.1.1150** и агентом **0.2.0-alpha.34**, исходный код агента **9f4b7337f41088a4e0b312a7c0f073d439b4cc43**. Проверка выполнялась от текущего интерактивного пользователя. Она не является приёмкой более нового исходного кода или другой учётной записи службы.

Отчёт real-windows-onec: начало **2026-11-09 08:24:49 UTC**, окончание **08:39:51 UTC**. SHA-256 полученного JSON: **e93145b2e34bb11f28805ae9ba5f1f86cabe4b26294794d15d79400805a9d2ce**. В репозиторий не включаются база, архивы, рабочие профили и платформенные журналы.

| Проверка | Фактический результат |
| --- | --- |
| Создание отдельного тестового источника | Успешно при эксклюзивном чтении исходной базы. |
| Локальная закрытая база, разрешение открытой базы выключено | ZIP восстановлен побайтно; лишнего предупреждения нет. |
| Локальная закрытая база, разрешение включено | ZIP восстановлен побайтно; лишнего предупреждения нет. |
| Локальный открытый сеанс, разрешение выключено | Копирование отклонено. |
| Локальный открытый сеанс, разрешение включено | Копия создана с предупреждением; согласованность открытой базы этим не доказывается. |
| Локальная база после закрытия сеанса | ZIP восстановлен побайтно; предупреждение исчезло. |
| Закрытая база через собственную UNC-папку, разрешение выключено и включено | Обе проверки прошли с побайтным восстановлением и без лишнего предупреждения. |

Пользователь отдельно сообщил: «Копия сделалась успешно. Я лично проверил в 1С». Это подтверждение проверки копии пользователем; оно не уточняет тип архива и не подменяет отсутствующие результаты выгрузки DT.

Общий результат сценария **success: false**. После unc-closed-true записано исключение System.Management.Automation.RuntimeException; точная причина требует текста предупреждения из PowerShell. Открытый сеанс через UNC, повторная закрытая UNC-база, выгрузка DT, восстановление DT и отмена выгрузки этим отчётом **не подтверждены**. Пункты 4.1–4.2 целиком не закрыты.

Сетевая проверка использует временную папку того же Windows-компьютера. Результат не распространяется на удалённый NAS, доменный SMB-сервер и работу службы под отдельной учётной записью.
