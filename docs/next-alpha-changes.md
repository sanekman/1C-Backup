# Следующий пакет после alpha.25

Новый выпуск пока не публикуется. Клиент остаётся alpha.25, сервер — preview.3.

- Для мониторинга внешних копий MS SQL добавлен выбор Windows-входа или SQL-логина. Пароль хранится в Windows Vault; JSON содержит только ссылку. Ручной и автоматический опрос используют общее подключение с обязательным TLS и проверкой сертификата. При смене сервера нужен новый пароль; новые источники не наследуют чужую привязку.
- Пароль несохранённого SQL-черновика не передаётся службе. Сохранение задания или источника подготавливает защищённый DPAPI-кэш до публикации настроек; установка службы экспортирует также пароли сохранённых источников мониторинга.
- В окне мониторинга убрана устаревшая надпись об отсутствии серверной отправки. Добавлены пошаговые указания по настройке SQL-мониторинга.

Следующая доработка не означает новый билд. Оповещения Telegram/MAX остаются отдельной задачей.

## Опубликованный пакет alpha.25

Изменения клиента **alpha.25** по сравнению с **alpha.24**. Сервер **preview.3** устанавливается отдельно.

## Windows-агент: удобство и надёжность

- Несохранённое задание защищено при «Отмена», Esc и полном выходе: можно сохранить, отказаться от изменений или вернуться в редактор. Сохранение доступно с любого шага и проверяет все настройки; ошибка проверки или записи оставляет черновик открытым. Сворачивание в трей сохраняет редактор без подтверждения. Неизменённое задание не вызывает лишних вопросов; импортированные и дублированные задания защищены сразу. Смена режима агента недоступна до закрытия редактора.
- Уточнено предупреждение о хранении инкрементной цепочки: архивы сверх лимита удаляются автоматически, когда перестают быть нужны сохраняемым копиям. Следующая полная копия сама по себе не гарантирует очистку всей старой цепочки.

- Ручной запуск через фоновый агент доступен после успешного восстановления его очереди. Медленное чтение или ошибка восстановления не разрешают повторную команду для уже принятого задания. Окно повторяет проверку; после восстановления другие задания снова доступны.
- В карточке выбранного файлового/WebDAV-задания виден сохранённый план: полная при каждом запуске, день недели полной копии с переносом пропуска либо число архивов в инкрементной цепочке. Для проверки плана не нужно открывать редактор.
- «Настройки» разделены на пять страниц: «Основное», «Фоновая работа», «Обновления», «Подключения» и «Помощь». Разделы всегда доступны сверху, текст крупнее, технические поля закрыты по умолчанию. Диагностика доступна в «Помощи», действия службы — в «Фоновой работе». Переключение разделов не меняет сохранённые настройки.
- Подсказка автозапуска направляет к установке службы Windows для работы без входа пользователя. Дорожные карты учитывают уже готовые службу агента и сервер мониторинга.

- Добавлено пошаговое руководство для первого запуска: установка, пробная копия с конкретными папками, проверка восстановления, расписание, служба, полная по дню недели, 1С, сеть, SQL и разбор ошибок. Кнопка в «Помощи» открывает установленный HTML без интернета; в комплект входит пример экрана настроек. README и инструкция в ZIP направляют к этому руководству.
- На пустом экране заданий доступна инструкция с пробной копией; ненужные до создания задания кнопки действий скрыты. Кнопка «Помощь на этом шаге» в мастере открывает нужный раздел локального руководства с учётом источника и текущего шага; заполненное задание остаётся открытым. Добавлены подробные шаги WebDAV/Nextcloud, пояснения выбора хранилища и корректная подсказка о работе службы без входа в Windows.

## Доведение Windows перед Linux

- Приоритет Windows зафиксирован в [списке готовности](windows-readiness.md); устаревшие отметки об отсутствии службы и управления ею исправлены. Новое развитие Linux отложено.
- MS SQL: выбор входа через Windows или SQL-логин. Пароль хранится в Windows Vault и защищённом экспорте службы, в JSON остаётся ссылка. Проверка источника и копирование используют одинаковое подключение. При импорте с другим SQL-сервером или без доступного пароля мастер требует сохранить данные заново; новые задания не наследуют чужой SQL-логин.
- PostgreSQL: поиск установленных утилит на Windows, выбор версии и согласованной пары pg_dump/pg_restore. Ручные пути доступны в отдельном блоке; неудачный поиск их не стирает.
- Пароль PostgreSQL можно задать в интерфейсе и передать службе через защищённый DPAPI-кэш. Он не попадает в JSON, аргументы процесса и архив; одноразовый файл подключения создаётся с закрытыми правами и удаляется после операции. Прежний способ входа сохраняется для старых заданий. Импорт на другое подключение требует нового пароля.
- Отдельный Windows CI проверяет настоящую службу агента под временным пользователем без входа в систему: SCM, задания при запуске и вручную, DPAPI-пароль архива, восстановление, остановка, повторный запуск и сохранение профиля при удалении службы.

## Проверка

Windows WPF-сценарий задерживает восстановление реальной принятой команды, имитирует временную ошибку, проверяет блокировку дубликата и восстановление работы. Проверка карточки задания сравнивает сохранённый день полной копии и возврат к числу архивов. Проверяются все пять разделов при размере окна 900 × 580, доступность основного действия без прокрутки, отсутствие одновременно открытых разделов и технических полей. Результаты сборки и CI фиксируются в PR №2.

Оповещения Telegram/MAX остаются отдельной задачей.
