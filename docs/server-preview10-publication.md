## Переход настоящего CT 107

Команды выполняет пользователь в Shell узла Proxmox после подтверждения
публикации. Получить закреплённый скрипт:

```sh
wget --https-only -O /root/update-sp-backup-server.py 'https://raw.githubusercontent.com/sanekman/1C-Backup/304c6bf962584dec7e0a8449a071bd2230ffd74c/deploy/server/create-proxmox-lxc.py'
```

Обновить существующий CT, сохранив напечатанный путь комплекта возврата:

```sh
python3 /root/update-sp-backup-server.py --update --id 107 --version 0.1.0-preview.10
```

При успешном завершении подключить системную задачу отдельной командой:

```sh
python3 /root/update-sp-backup-server.py --enable-web-updates --id 107
```

Затем открыть панель, войти и проверить «Настройки → Обновление сервера»:
текущая версия preview.10, проверка выпусков без ошибок, сохранены агенты,
задания и история. Пока нет более нового выпуска, отсутствие предложения
установки ожидаемо. Сам переход кнопкой остаётся отдельной будущей проверкой.
Проверить также иерархию агентов: «Управление папками» → создать организацию →
«Добавить подпапку» для филиала → ещё одну подпапку для отдела. В карточке
агента через изменение имени/папки выбрать отдел. На главной странице дерево
должно раскрывать уровни, а выбор организации показывать агентов её подпапок.
Изменение родителя переносит всю ветку; удалить можно только пустую папку.
Этот механизм уже реализован и включён в пакет; новые плоские группы не нужны.

Пароли и файлы секретов в отчёт не включать.
