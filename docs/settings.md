# Настройки программы

Эта структура доступна начиная с alpha.25. В alpha.24 настройки находятся на одной общей странице.

Настройки разделены на пять страниц. Кнопки перехода всегда видны сверху; при переключении открывается только выбранная страница.

| Раздел | Что здесь находится |
| --- | --- |
| Основное | Тема оформления и переход к созданию задания. Для обычного копирования другие подключения не обязательны. |
| Фоновая работа | Автозапуск после входа в Windows, служба для работы без входа пользователя, отдельный режим расписания в окне. |
| Обновления | Проверка и установка новой версии, автоматическая проверка. Предварительные версии и доступ к закрытому GitHub — в дополнительных параметрах. |
| Подключения | Подключение по приглашению, выбор локальных или серверных заданий и переход к оповещениям. Шлюзы и диагностика связи — в блоке для опытных пользователей. |
| Помощь | Сохранение диагностики, открытие логов и копирование версии для поддержки. |

Основные действия и статусы видны сразу. Развёрнутые требования к службе, состав диагностики и сведения о сборке открываются по запросу. Навигация между страницами сама не меняет настройки.

Для копирования после закрытия окна нажмите «Включить автоматически» в верхней панели программы. Для запуска после входа в Windows включите автозапуск в «Фоновой работе». Если копии должны создаваться до входа пользователя, раскройте настройку службы в том же разделе и задайте пользователя Windows с нужными правами.
