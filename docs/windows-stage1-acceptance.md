# Приёмка этапа 1: интерфейс Windows

Дата: 8 ноября 2026 года. Проверяемый исходный код: `bd182b770e0c81ba5ae6e1fffe33b55bd08d28eb`.

Этап включает компактное окно, результаты предварительных проверок, действия с отчётом, принятые ручные запросы и прогноз расписания. Проверки выполнены на GitHub-hosted Windows (`windows-latest`); это не вся матрица поддерживаемых Windows.

## Подблоки и доказательства

| Подблок | Проверенный результат |
| --- | --- |
| 1.1. Компактное окно | Исходные проверки геометрии пройдены: строки заданий не обрезаны, основные кнопки доступны, раскрытый отчёт помещается в области прокрутки. Скрытые панели не занимают место. |
| 1.2. Результаты | В отчётах отражены исполнитель, время, длительность и итог; проверка источника из окна явно не подтверждает права службы. Отмена и ошибка получения ответа не обозначаются успехом. |
| 1.3. Действия с отчётом | Windows UI проверяет повтор, смену задания, устаревание, TXT, отказ перезаписи, совпадение текста с буфером обмена и очистку без изменения источника, заданий, истории и каталога копий. Профильные тесты проверяют отмену записи и конкурентный экспорт. |
| 1.4. Ручные запуски | Проверены восстановление очереди после открытия окна, временная ошибка чтения, чужие подтверждения, защита от дубля и независимость других заданий. Установленная служба проверяет ручной запуск выключенного задания и повторную доставку завершённого запроса. |
| 1.5. Прогноз | Windows UI проверяет пояснения выбранного задания и переключение расписания; тесты ядра проверяют три ближайших времени, недельный план, ручное/выключенное/стартовое задание, часовой пояс и неизменность сохранённых параметров. |
| 1.6. Общая приёмка | Общий UI-прогон, нативная служба, SMB, SQL и установочный пакет проверяются одним накопленным кандидатом. Снимки компактного окна, отчёта и ручной очереди просмотрены. |

## Границы приёмки

Этап 1 завершает этот пакет интерфейса. Проверки реальных сеансов 1С, удалённого MS SQL, доменного входа, перезагрузки отдельной машины и всех целевых версий Windows относятся к последующим этапам дорожной карты. LocalDB и `windows-latest` не заменяют эти стенды.

Приёмка не создаёт нового выпуска. Публичные версии остаются Windows `v0.2.0-alpha.34` и Server `v0.1.0-preview.8`; старые теги и файлы не заменены. PR №2 остаётся открытым черновиком.
