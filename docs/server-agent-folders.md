# Папки, подпапки и понятные имена агентов

Эта возможность добавлена в рабочую ветку после server preview.5 и ещё не опубликована. Обновление Windows-агента для неё не требуется: имя и папка задаются на сервере.

## Создайте структуру

1. Войдите в панель сервера как администратор.
2. В разделе «Агенты» слева нажмите «Управление папками».
3. Введите имя, например «Клиенты». Для первой папки оставьте родителя «Верхний уровень» и нажмите «Создать папку».
4. Возле созданной папки нажмите «Добавить подпапку». Введите, например, «Компания Альфа» и сохраните.
5. При необходимости создайте внутри неё подпапки «Главный офис» и «Филиал». Получится структура: Клиенты → Компания Альфа → Главный офис.

Папку можно переименовать или перенести: нажмите её путь в списке, измените имя или родителя и сохраните. Вместе с папкой перемещаются её подпапки и агенты. Нельзя помещать папку внутрь себя или собственной подпапки. Допускается до 16 уровней и 1000 папок на сервер.

## Добавьте агента в нужную папку

1. Вернитесь в раздел «Агенты» и выберите папку в дереве слева. Стрелка раскрывает подпапки, нажатие имени открывает агентов этой ветки.
2. Нажмите «Подключить агент». Выбранная папка уже подставлена; её можно изменить в списке.
3. Введите **понятное имя агента**, например «Бухгалтерия — главный сервер». Это название в панели, оно не обязано совпадать с именем компьютера Windows.
4. Если нужной папки ещё нет, раскройте «Создать новую папку внутри выбранной» и введите её имя. Если выбрано «Без папки», новая папка появится на верхнем уровне. Она будет создана вместе с приглашением, агент попадёт в неё при подключении.
5. Нажмите «Создать приглашение». Перенесите адрес сервера и код в настройки подключения Windows-агента. Для обычного нового агента дополнительные параметры менять не требуется.
6. После подключения найдите агента в выбранной папке. Основное название — заданное вами имя; рядом отдельно показано имя компьютера.

В список выбранной папки включены агенты всех её подпапок. «Все агенты» показывает весь сервер, «Без папки» — только агентов, которым папка не назначена. Общая сводка мониторинга относится ко всему серверу.

## Измените имя или папку существующего агента

1. Откройте карточку агента.
2. Нажмите «Изменить имя и папку».
3. Введите новое понятное имя и выберите папку. Здесь также можно создать новую подпапку.
4. Нажмите «Сохранить имя и папку».

Останавливать копирование и подключать компьютер заново не нужно. ID, токен подключения, задания, расписания и история сохраняются. Старые агенты без специально заданного имени первоначально отображаются под именем компьютера; их можно переименовать этим же способом.

## Удаление папки

В «Управлении папками» нажмите путь нужной папки, раскройте «Удалить эту папку» и нажмите «Удалить пустую папку». Сервер не удалит папку, пока в ней есть агенты, подпапки или действующие приглашения. Перенесите агентов через их карточки, подпапки — через изменение родителя. Для неиспользованного приглашения дождитесь окончания срока действия. Копии и история при удалении пустой папки не удаляются.

## Обновление сервера

Для этой возможности добавлена транзакционная миграция PostgreSQL **4 → 5**. Имена существующих компьютеров переносятся в отдельное поле, агенты остаются без папки; токены и история сохраняются. Перед обновлением нужна проверенная резервная копия базы, настроек и ключей сервера. Возврат на preview.5 требует восстановления базы со схемой 4 из этой копии: старый сервер не запускается с новой схемой. Нового выпуска пока нет.
