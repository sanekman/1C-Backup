# 1C-Backup — дистрибутив Windows x64

Эта ветка содержит переносимый дистрибутив начальной версии. Основная ветка main не изменена.

[Скачать ZIP (около 65 МБ)](https://github.com/sanekman/1C-Backup/blob/distribution/windows-x64-preview/windows/1C-Backup-windows-x64.zip?raw=true)

Распакуйте весь архив и запустите `1C-Backup/OneCBackup.Desktop.exe`. .NET включён в архив, отдельная установка не требуется. Инструкция находится в `START-HERE.txt`.

[Контрольная сумма SHA256](windows/1C-Backup-windows-x64.zip.sha256).

Сборка, состав Windows x64 и целостность ZIP проверены в облачной Linux-среде. Запуск интерфейса и копирование реальных баз требуют проверки на Windows. Служба Windows и автоматическое подключение GUI к серверу управления пока не реализованы. Архив собран из рабочей версии в облачной среде; исходники этой версии пока не отправлены в main.
